# 🚗 Car Market Trends Analysis Using CarDekho Data

## Project Overview

This project analyzes the **CarDekho used-car dataset** using Python to identify factors affecting used-car selling prices and understand market trends.

The project was completed as part of a **Data Analytics Internship** and demonstrates practical skills in data cleaning, exploratory data analysis, visualization, feature engineering, and machine learning.

## Problem Statement

Used-car prices vary based on factors such as vehicle age, present price, kilometres driven, fuel type, seller type, transmission, and ownership history. The objective of this project is to analyze these factors, understand resale-value patterns, identify important market segments, and predict used-car selling prices.

## Objectives

* Clean and validate the dataset.
* Identify duplicates and missing values.
* Analyze selling-price distributions and trends.
* Study the relationship between selling price and vehicle characteristics.
* Compare fuel type, seller type, transmission, and ownership segments.
* Analyze vehicle depreciation and price retention.
* Identify high-value and high-retention car models.
* Build machine-learning models for selling-price prediction.

## Dataset

The dataset contains **301 records and 9 variables**, including:

`Car_Name`, `Year`, `Selling_Price`, `Present_Price`, `Kms_Driven`, `Fuel_Type`, `Seller_Type`, `Transmission`, and `Owner`.

After cleaning, duplicate records are removed before analysis.

## Key Insights

The analysis indicates that **Present Price is strongly associated with Selling Price**. Vehicle age is negatively related to resale value, while fuel type, seller type, and transmission show meaningful differences in average selling prices.
